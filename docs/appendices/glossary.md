# 付録C 用語集

[← 付録B 完成時のAPI仕様](api-spec.md) · [目次](../README.md) · [付録D 講師用の教材整備TODO →](instructor-todos.md)

- **認証**：認証情報を確かめ、どのアカウントとして扱うかを判断すること。
- **認可**：その利用者に、対象データや操作へのアクセスを許すか判断すること。
- **セッション**：複数のリクエストにまたがる状態。この教材ではログイン状態を表す。
- **トークン**：セッションを利用するためにブラウザが持つ秘密の値。
- **ハッシュ**：入力から計算した値。用途に応じたアルゴリズムを選び、照合などに使う。
- **ソルト**：パスワードのハッシュ化ごとに加えるランダムな値。
- **Cookie**：ブラウザが保存し、条件に合うHTTPリクエストで送る情報。
- **オリジン**：URLのスキーム・ホスト・ポートの組。
- **マイグレーション**：DB構造の変更を、再現できる履歴として管理・適用すること。
- **一意制約**：同じ値の重複をDBで防ぐ制約。
- **外部キー**：別のテーブルの行との対応を保つための項目・制約。
- **ミドルウェア**：ルートの処理の前後で、共通処理を実行する仕組み。
- **単体テスト**：小さな関数などを対象に、振る舞いを確認するテスト。
- **結合テスト**：API・認証処理・DBなど、組み合わせた処理を確認するテスト。
- **境界値**：有効・無効などの判断が切り替わる境目の値。
- **回帰**：変更によって、以前満たしていた仕様が壊れること。
- **CSRF**：別のページから、利用者のブラウザに意図しない操作を送らせる攻撃。
- **XSS**：攻撃者の用意したスクリプトが、アプリのページ上で実行される問題。
