# 認証をつくる

## Next.js・Hono・Prismaで学ぶ認証と認可

**生徒用教材**

- 対象：Web開発の基礎を学び、Better Authによる認証・認可を使ったことがある人
- 使用技術：Next.js / Hono / Hono RPC / Prisma / SQLite / TypeScript / Vitest
- 出発点：誰でも同じメモを操作できるアプリ
- 完成形：ログインした利用者が、自分のメモだけを操作できるアプリ

> このリポジトリの認証なしメモアプリに、各章の課題に沿って認証・認可を追加します。「TODO（教材整備）」は講師が教材を仕上げるための項目です。生徒が取り組む内容は「課題」として示します。
